блин44ики

ингридиенты:

  • мука - 80гр
  • яйко - 1шт
  • разрыхритель - пол ч.л.
  • вада +- 120мл
  • сахарок и соль - по вкусу
  • масло (для жарки)

приготовление:

  1. смешать яйца, сахар, соль, разрыхлитель. влить воду, перемешать.
  2. постепенно всыпать муку, размешивая до однородности (без комков)
  3. разогреть сковороду, смазать маслом. выпекать тонкие блины с обеих сторон до золотистого цвета
  4. ПРИЯТНОГО АППЕТИТА НАФИК!!!!

котлеты.

ингридиенты:

  • фарш - 500 гр
  • яйко - 1 шт
  • мука - 2-3 с.л.
  • вода - 2-3 с.л.
  • соль - по вкусу
  • разрыхлитель - 0.5 ч.л.
  • масло (для жарки)

приготовление:

  1. смешать фарш, яйцо, муку, воду, соль, разрыхлитель. тщательно перемешать до однородности.
  2. влажными руками слепить котлеты желаемой формы.
  3. обжарить котлеты на разогретой сковороде с маслом до золотистой корочки с обеих сторон. для большей готовности можно потушить под крышкой с добавлением небольшого количества воды.
  4. ЕЕЕ НЯМАТЬ ПОДАНО

пюрешка

ингридиенты:

  • картофан - 500гр
  • молоко - 100 мл
  • яйко - 1 шт
  • соль - по вкусу

приготовление:

  1. картофель очистить, нарезать, залить водой, посолить и варить до готовности
  2. слить воду, оставить немного(100 мл) на дне.
  3. картофель размять толкушкой.
  4. влить молоко, добавить яйцо, соль по вкусу, тщательно перемешать до однородной консистенции
  5. если есть блендер, то в конце взбить 1-2 мин
  6. bon appetit
